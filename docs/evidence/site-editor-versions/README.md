# Estúdio de páginas com versões — verificação local

O código local integra o estúdio com o catálogo assinado Node/Go/browser: endereço estável, história fixa ou actual, rascunho cifrado com base/UUID/leitores/prazo, publicação idempotente, conflito explícito e recuperação com os leitores originais. O proprietário confirma a pré-visualização verificada antes de substituir o rascunho; a recuperação só publica quando escolhe Publicar página. A leitura e o seeding não conferem autoria.

O [relatório](report.json) distingue os resultados preservados e as repetições. A regressão compreende410testesNode (409PASS inicialmente; uma entrada de tradução corrigida e o conjuntoi18n repetido), Go/race,69interop,SQLiteC,32UI Node e32UI Go,73casos por browser (219),9UI-RNS,24testeshostiOS/estática e Linuxbuild/run/package/run. O valor native seleccionou efectivamente Go e o teste consultou nativeRuntime. A [errata](../site-ui-runtime-correction) preserva os dois drivers históricos que tinham contadoNode comoUI Go.

**Observação de fiabilidade ainda aberta:** uma execuçãoFirefox fechou o canal depois de cancelar retransmissão; o SOS próprio chegou e o conteúdo cancelado não chegou ao destino. A primeira matriz ficou72PASS/1FAIL. Foram acrescentados diagnósticos e passaram cinco repetições, os oito casos do ficheiro e a repetição integral de73casos. A causa não foi demonstrada, por isso não se afirma que foi corrigida. A primeira falha e os metadados das repetições estão preservados; os passes posteriores não apagam a ocorrência.
