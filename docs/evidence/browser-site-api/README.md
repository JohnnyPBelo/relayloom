# Sites versionados no browser — verificação local

Implementados catálogo IndexedDB cifrado, transacções de valores privados, runtime serial, API no worker e validação antes de aceitar/transmitir sites. Endereço estável, pedidos idempotentes, conflitos, histórico, quota, expiração e recuperação têm testes reais. Um leitor/seeder conserva a assinatura do autor; não ganha autoridade de edição.

O [relatório consolidado](report.json) contém 66 cenários por engine (198 combinações engine/cenário). A primeira regressão executou 65 por engine: Chromium e Firefox passaram todos; WebKit passou 64 e falhou um selector global que encontrava dois estados legítimos. A [primeira execução permanece FAIL](first-full-regression.json). O teste passou a procurar dentro do landmark Estúdio do site e foi repetido em todos os engines, juntamente com um novo percurso do worker compilado: [repetição PASS](recheck.json). Não foram alterados prazos, asserções funcionais, código do produto ou assets entre essas execuções. A comparação de hashes conserva os outros resultados. O relatório não conta repetições como novos cenários.

Também passaram 17 casos dirigidos por engine: transacção/rollback, handle encerrado, operações assíncronas abandonadas, chave de sessão, CAS, corrupção, quota real de bytes cifrados, preparação privada, expiry, replay, resolução sem fallback, leitura sem autoria e conflitos. O erro inicial da fixture Mesh.stop e o cálculo inicial errado da quota ficaram nos logs. As repetições corrigidas passaram sem alterar limites do produto.

Seis percursos de rede (dois por engine) usaram Browser→Browser→Node→Go e Browser→Browser→Go→Node, com WebRTC, WebSocket e TCP reais. Incluem controlos negativos com relay pausado, entrega após autorização, três saltos observados, histórico exacto, privado opaco, recusa de reassinatura, retorno nativo e seeder único reiniciado com o autor e os nós nativos encerrados. Os ficheiros *-network.json registam os resultados e PIDs das fixtures; não há prova de rádio físico ou de dois dispositivos físicos.

Reprodução: `npm run build`; `npm run native:build`; `RELAYLOOM_MATRIX_ENGINE=chromium node scripts/e2e.mjs --config tests/browser/matrix.config.ts`, repetindo com firefox e webkit. Para o conjunto dirigido, acrescentar os ficheiros site-catalog.spec.ts, site-api.spec.ts, private-values.spec.ts e application-api.spec.ts do directório tests/browser. Os argumentos exactos usados, datas e durações estão nos relatórios. Os drivers locais são `.cache/site-browser-final/run.mjs` e `recheck.mjs`; não relançar os handles já recolhidos por perda de contexto.

As capturas mostram a regressão do estúdio existente e da leitura de uma página guardada, com Axe sem violações. Não mostram novos controlos de revisões. As traces brutas ficaram na cache local; os logs públicos foram sanitizados e os ficheiros têm [hashes](manifest.json). Esta revisão do autor e os testes automáticos não são a revisão independente do contrato.

A UI de histórico/endereço/recuperação/base persistente está em preparação isolada. Nada deste marco foi publicado ainda no HTML público, que continua na fonte 0c6b58a / distribuição45ecacdf. Grupos dinâmicos web, dados/contribuições declarativas, ficheiros opcionais, backup/rotação/keystore, empacotamento de todos os meios/plataformas, Apple/hardware e restantes requisitos continuam pendentes. O produto não está concluído nem validado para catástrofes.
